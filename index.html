01. About

What I actually do

I am an entry-level penetration tester based in Bangalore, holding the EC-Council CPENT v2 and CEH v13 certifications. My focus is offensive security: finding real weaknesses before someone with worse intentions does, then documenting them clearly enough that an engineering team can actually fix them.

Most of what I know, I proved under exam conditions rather than just studying for a badge. In the CPENT practical exam I compromised a segmented Active Directory forest, built a working remote buffer overflow exploit from scratch, reverse engineered six firmware images, and chained web and Linux privilege escalation bugs into full host compromise, all documented with evidence. Outside the exam room, I built and shipped WebShield.AI (a phishing detection browser extension) solo, from research to two browser store launches, I maintain WebRecon, an open source reconnaissance tool, and I built VulnProbe, a 16 module web vulnerability scanner with scope enforcement and confidence scored findings.

05. Projects

Things I have shipped

VulnProbe

Web Vulnerability Scanner

Web Application Vulnerability Scanner (DAST) . 2026 . Python & Flask

An authorization first web application security scanner. It crawls a target, runs 16 pluggable security modules, and produces evidence backed findings with confidence levels, CWE and OWASP mapping, and PDF and JSON reports, through a web dashboard, REST API, or CLI.

  • 16 detection modules: reflected XSS, error based and time based blind SQLi, OS command injection, SSRF, path traversal, CORS, CSRF, open redirect, clickjacking, Host header injection, sensitive file exposure, directory listing, and header and cookie audits.
  • Scope and safety core: every request and redirect hop is validated against an authorized scope, private and loopback targets are blocked via DNS resolution, scans require explicit authorization, and traffic is rate limited.
  • Verification engine that labels each finding confirmed, probable, or unverified, with out of band (OAST) token correlation to cut false positives on SSRF and blind command injection.
  • Playwright crawler with a requests fallback, endpoint discovery from JavaScript and OpenAPI specs, authenticated scanning with secret redaction, diagnostics that explain zero finding scans, optional Nuclei and OWASP ZAP adapters, and a 170 test offline pytest suite.
